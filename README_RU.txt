ДЕНЬ ЗА ДНЁМ — личный трекер, версия 1.0

ЧТО ВНУТРИ
- Календарь с выбором дня.
- Счётчики воды, экранного времени, учёбы и активности.
- Сон: время начала и пробуждения, автоматический расчёт длительности.
- Оценки сна, настроения, энергии, концентрации и мотивации.
- Привычки и отметки выполнения.
- Заметки о питании и событиях дня.
- Свои показатели: число, счётчик, оценка 1–10, да/нет, заметка, временной интервал.
- Статистика за 7, 30 и 90 дней.
- Экспорт и импорт резервной копии JSON.
- Офлайн-кэш после первого открытия по HTTPS.

ВАЖНО О ДАННЫХ
Приложение не имеет аккаунта и сервера. Все записи сохраняются локально в браузере на данном устройстве. Для переноса на другой телефон используй «Настройки → Экспортировать JSON», а на другом устройстве — «Импортировать JSON». Автоматической синхронизации между устройствами в версии 1.0 нет.

КАК ЗАПУСТИТЬ ДЛЯ ПРОВЕРКИ
Открой index.html в браузере. Для полноценной установки PWA на Android и офлайн-режима нужен HTTPS-адрес (например, GitHub Pages).

КАК УСТАНОВИТЬ НА ANDROID ЧЕРЕЗ GITHUB PAGES
1. Создай репозиторий на https://github.com/new (например, day-by-day).
2. Распакуй ZIP. Открой папку lifelog_android и загрузи ВСЁ ЕЁ СОДЕРЖИМОЕ в корень репозитория: index.html, manifest.webmanifest, sw.js, README_RU.txt и папку icons.
3. В репозитории открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch, Branch: main, Folder: /(root), затем Save.
5. После публикации открой адрес вида https://ТВОЙ-ЛОГИН.github.io/day-by-day/ в Chrome на Android.
6. В Chrome нажми ⋮ → «Установить приложение» или «Добавить на главный экран».

Не публикуй в репозитории личные резервные копии JSON: в них находятся твои записи. Сам код приложения не содержит личных данных.
